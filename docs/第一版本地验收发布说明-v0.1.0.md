# 第一版本地验收发布说明 v0.1.0

发布日期：2026-09-17
版本定位：第一版本地验收基线。

## 已完成能力

v0.1.0 完成了阶段 1～13 的开发与本地验收：七类 Contract 与枚举、SQLite 迁移、TaskState、ContextPack、Harness 与硅基流动适配、规划/生文/审查/记忆主链路、记忆权限与人工确认、返工和裁决路由、固定 Mock 验收、真实五场模型测试，以及隔离备份恢复。

主链路为：`ScenePlan → ProseDraft → 三位 ReviewerResult → QualityReport → MemoryProposal`。所有模型调用经 Harness 独立隔离并写入 `harness_calls`；Agent 不直接访问模型、数据库或其他 Agent。

## 阶段 1～13 验收结论

- 阶段 1～11：Contract、状态、数据库、Harness、ContextPack、Agent 薄适配与 12 个固定验收分支通过。
- 阶段 12：硅基流动 DeepSeek 的五场真实调用主链路通过；3～5 场连续处理、人工确认、断点恢复、跨作品隔离和历史不可覆盖均有证据核验。
- 阶段 13：备份清单校验、整库隔离恢复、单条历史正文/记忆恢复、阻塞单场恢复与恢复后续跑的本地验收通过。

详细证据见 [阶段12真实模型验收报告-v1.md](阶段12真实模型验收报告-v1.md) 与 [阶段13备份恢复最终验收报告-v1.md](阶段13备份恢复最终验收报告-v1.md)。

## 真实五场测试结论

真实五场测试共完成 30 次成功 Harness 调用：每场包含规划、生文、世界审查、剧情审查、风格审查和记忆提取。ScenePlan、ProseDraft、QualityReport、MemoryProposal 与调用记录按场次、版本和 hash 关联。

测试同时发现并修复过 Contract 类型、结构化审查、记忆枚举、缺失 `target_key`、恢复覆盖历史等问题。真实调用记录和测试数据库不进入此版本库；脱敏回归样本和验证代码保留在仓库内。

## 断点恢复与历史保护

已完成场次在 sequential 恢复时零新增调用；异常恢复会复用有效 Plan、Draft、Report 与 Proposal，从失败节点继续。历史业务记录采用仅插入语义：同编号同内容可复用，同编号不同内容拒绝覆盖；明确返工才创建新版本。

## 当前未完成的生产事项

本版本不得宣称已经稳定产出 20 万字。尚未完成：

- 20～40 场规模测试；

- 生产环境的每日备份调度、保留策略、失败告警和管理后台部署；
- 在生产环境中持续测量模型成本、RPO、RTO 和长期质量漂移。

下一阶段先进行 20～40 场规模测试，再开展 160 场完整作品验证和生产环境运维配置。
