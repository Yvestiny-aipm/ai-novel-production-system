# CreativeBrief 固定填写模板

> 一部作品填写一份。保留所有固定字段；暂未确定的内容填「待定」，不要把猜测写成已确认设定。确认后的修改通过新版本记录。

## 0. 作品信息

- **作品名称（title）**：【暂定书名】
- **故事主题（theme）**：【故事最终探讨的问题或主角的核心成长，一句话】
- **目标篇幅（target_length）**：【预计总字数，填数字】
- **版本状态**：【草稿 / 已确认】

## 一、故事方向

### 1. 题材与卖点（genre）

- **故事背景**：【都市 / 校园 / 古风 / 玄幻仙侠 / 末世生存 / 异世界 / 悬疑 / 种田经营 / 争霸权谋；可组合或自填】
- **核心设定**：【穿越 / 穿书 / 重生 / 系统 / 隐藏身份等；说明具体机制】
- **核心看点**：【逆袭打脸 / 复仇 / 甜宠 / 身份反转 / 经营致富等；选 1～3 个】
- **故事风格**：【轻松 / 热血 / 温暖 / 悬疑 / 虐心 / 暗黑等】
- **一句话卖点**：【主角处境 + 特殊设定 + 最吸引人的冲突或反转】

- **核心规则（core_rules）**：
  1. 【规则；适用范围、限制和代价】
  2. 【规则；适用范围、限制和代价】

## 二、故事结构

- **故事梗概**：【用 2～4 句话交代主角、目标、阻碍、关键反转和结果方向】
- **主线矛盾（main_conflict）**：【主角想要什么；谁或什么阻止；失败会失去什么】

### 1. 开端：人物与事件出现

- **主角初始处境**：【身份、困境、当下缺少什么】
- **引发事件**：【什么事迫使主角行动】
- **阶段目标**：【主角决定先做什么】

### 2. 发展：行动与阻碍升级

- **主角行动与获得的帮助**：【关键尝试、伙伴或资源】
- **第一次失败及代价**：【失败在哪里，失去什么】
- **新敌人或秘密**：【发现了什么，如何改变原有判断】
- **更严重的危机**：【冲突如何升级，为什么不能退回原点】

### 3. 高潮：最大冲突爆发

- **正面较量**：【主角与主要对手如何交锋】
- **关键选择与代价**：【主角必须在什么之间选择，承担什么后果】
- **外部冲突的解决**：【主线目标与最大危机如何落定】
- **内心问题的解决**：【主角的认知或行为发生什么变化】

### 4. 结局：结果落定

- **结局方向（ending_direction）**：【圆满 / 开放 / 悲剧 / 阶段性胜利 / 留有续作空间】
- **最终结果**：【主角是否达成目标，主要人物与世界发生什么变化】
- **保留的悬念**：【如有续作空间，写明尚未解决的问题；没有则填「无」】

## 三、核心人物

> 每位主要人物按同一格式填写。可复制人物卡；角色兼任时注明，无需重复创建人物。

### 人物卡：【姓名】

- **故事职能**：【主角 / 重要配角 / 主要对手 / 感情对象；可兼任】
- **公开身份与隐藏身份**：【填写；没有隐藏身份则填「无」】
- **性格与行为特点**：【用可在情节中表现的行为描述】
- **目标与动机**：【想得到什么；为什么想得到】
- **能力与资源**：【能做什么；掌握什么】
- **弱点与限制**：【做不到什么；最怕失去什么】
- **人物弧光**：【从开端到结局的关键变化】
- **与主线的关系**：【如何帮助或阻碍主角】

## 四、创作约束

- **风格要求（style_requirements）**：【叙事视角、语言节奏、情绪浓度，以及希望避免的表达】
- **特别要求（special_requirements）**：【必须出现或禁止出现的内容；没有则填「无」】

---

**提交前检查**：题材组合能否从一句话卖点看出来；人物目标是否直接推动主线；核心规则是否有边界与代价；开端、发展、高潮、结局是否因果相连；结局是否回应主角的外部目标和内心问题。
