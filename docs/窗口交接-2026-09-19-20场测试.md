## 5. 主链路和三类失败（不要混）

```text
Planning / ScenePlan
→ 规划质量门槛（含推进目标是否空泛）
→ Writing / ProseDraft
→ 后端真实字数
→ 实质重复
→ 三位审查员
→ 剧情推进核验
→ QualityReport
→ 记忆提取
→ 自动保存或人工确认
→ 下一场
```

| 类型 | 计数 | 路由 |
| --- | --- | --- |
| 字数失败 | `length_failure_*`，不占内容次数 | 只回 Writing；同一 Plan 最多 4 份长度稿，第 4 份仍失败则 `length_attempts_exhausted` |
| 剧情内容失败 | `content_attempt_in_plan` / `content_attempt_total` | 第 1、2 次回 Writing；第 3 次回 Planning 并增加 `plan_attempt`；新周期再失败则 `content_attempts_exhausted` |
| 正文完全相同 | 立即 `duplicate_draft_content` | **当场 blocked**，不等三次 |
| 规划质量失败 | 只增加 `plan_version` | 回 Planning，不增加 `plan_attempt` |
| 技术故障 | `technical_retry_count`、异常队列 | 不占字数/内容次数 |

`plan_version` 和 `plan_attempt` 不是同一个数字。
